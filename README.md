En esta materia trabajamos con programacion y electronica utilizando Arduino, realizando circuitos basicos y secuencias con componentes electronicos como LEDs RGB,
buzzers, pulsadores y potenciometros.

Organizacion de la branch:

Consigna a resolver:
Desarrollar un codigo y un esquema electronico basico que haga una secuencia de luces con 3 LEDs RGB.

Secuencia solicitada:
Encender el 1° LED en color rojo fuerte utilizando salida analogica.
Apagar el 1° LED y encender el 2° LED en color magenta utilizando salida digital.
Apagar el 2° LED y encender el 3° LED en color cian clarito utilizando salida analogica.
Repetir la secuencia infinitamente.

Entre cada cambio de color realizar un sonido con un buzzer, y el sonido no debe durar mas de 100 ms, utilizando variables para organizar los pines utilizados.
